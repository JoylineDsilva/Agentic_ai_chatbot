# Agentic_ai_chatbot
Simple Agentic AI Chatbot
Overview

The Simple Agentic AI Chatbot is an AI-powered chatbot that uses an agent-based workflow to understand user queries, decide the appropriate action, and generate intelligent responses. The chatbot can perform tasks such as answering questions, searching the web, and generating/executing Python code using external AI tools and APIs.

This project demonstrates the concepts of:

Large Language Models (LLMs)
AI Agents
Tool Calling
Planning and Decision Making
Web Search Integration
Code Generation and Execution

The chatbot provides an interactive interface using Streamlit and integrates APIs such as Groq API and Tavily API for enhanced functionality.

Features
Intelligent conversational chatbot
Agent-based decision making
Web search functionality using Tavily API
Python code generation and execution
Interactive Streamlit user interface
Real-time response generation
Simple and beginner-friendly implementation
Technologies Used
Python
Streamlit
Groq API
Tavily API
LLM (Large Language Model)
Machine Learning Concepts
